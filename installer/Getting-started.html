Market Lens Local

A crypto futures research dashboard running on your Windows PC.

Open your dashboard

Double-click Market Lens Local on the desktop or in the Start menu. The launcher starts the local service and opens Brave, or your default browser. No Node.js installation or commands are needed.

Open dashboard · Collector status and backups

Choose what to analyse

  • All Markets: click Refresh to scan active USDT perpetuals. Use search, filters and 15m/1h timeframes.
  • Watchlist: star coins to save them on this PC.
  • Overall Direction: review 15m, 1h and 4h context. Historical recovery can supply 4h context when provider access and aligned history are available. Otherwise the app collects measured observations; missing or stale history remains explicitly unavailable.
  • Trade Confirmation: search for a coin, select it and click Analyse it. Review the reasons and any unavailable inputs.
  • User Guide: open or download the bundled PDF for the signal rules, data warnings and review checklist.
The screen changes only when you request new data. Background collection continues after closing the browser while your PC is awake and online. Sleep and shutdown pause collection.

Startup, stopping and updates

The installer offers automatic collection at Windows sign-in. To stop it now, use Stop background collection in the Start menu. To disable sign-in startup, open Windows Startup Apps and disable Market Lens, or remove its shortcut from the Startup folder.

Download updates from GitHub Releases and run the new installer. Automatic updates are not enabled.

Your saved data

Watchlists, history, backups and logs are stored under %LOCALAPPDATA%\Market Lens Local\data. They are preserved across updates and uninstall. Use This PC in the dashboard to download a backup. Uninstall the app through Windows Settings → Apps.

If it does not open

Wait up to two minutes on the first launch. Only one Market Lens installation may use the default local ports. Stop any earlier source installation before opening this version. Check the service log under %LOCALAPPDATA%\Market Lens Local\data\logs if startup fails.

Before using a signal

Rule agreement is not a win probability. This app does not execute trades, and no profitability is promised. Exchange outages, regional restrictions and delayed data remain visible. A successful refresh confirms data loading, not a successful trade.
